# CarbonTrade – Carbon Credits Trading Platform

## 📌 About the Project
CarbonTrade is a web-based platform designed to make carbon credit trading simple and transparent. It connects buyers and sellers of carbon credits and helps users contribute to environmental sustainability.

## ✨ Features
- **Home Page:** Displays an overview of the platform.
- **Carbon Credit Marketplace:** Browse carbon credits from different projects.
- **Credit Information:** View prices, locations, available credits, and project details.
- **Shopping Cart:** Add carbon credits to the cart.
- **Buy Credits:** Purchase carbon credits through the platform.
- **Dashboard:** View portfolio performance, carbon credits owned, and CO₂ impact.
- **Recent Activity:** Track recent carbon credit transactions.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- TypeScript
- Vite
